# Issue Tracker: Local Markdown

Issues are tracked as local markdown files within the `.scratch/` directory.

## Conventions
- Each feature or task should have its own directory: `.scratch/<feature-name>/`
- Each issue is a markdown file within that directory.
- Files should follow a naming convention (e.g., `issue-1.md` or `description.md`).
- The `to-tickets` and `triage` skills should use this directory structure to create and read issues.
