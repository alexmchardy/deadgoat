# Triage Labels

The following labels are used by the `triage` skill to categorize and prioritize issues:

- `needs-triage`: The issue has been submitted and needs initial review.
- `needs-info`: More information is required from the reporter before work can begin.
- `ready-for-agent`: The issue is well-defined and ready for an AI agent to begin work.
- `ready-for-human`: The issue is well-defined and ready for a human developer to begin work.
- `wontfix`: The issue will not be addressed at this time.
